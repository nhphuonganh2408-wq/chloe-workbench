# Chloe's Workbench

A small personal workbench for university, IELTS, ACCA, and a startup project.

The page supports English and Simplified Chinese. Use the language switch at the top right; your selection is remembered in the browser.

## Weekly study schedule

- IELTS: Monday, Wednesday, Friday at 5:00 PM
- ACCA: Thursday at 6:00 PM and Sunday at 9:00 AM

The page is a static site. Publish the repository root with GitHub Pages to share it publicly.
